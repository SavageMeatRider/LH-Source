About

What is LH?

Last Hit is a Forge mod for TNT Tag. It gives you an edge by tracking the last-hit mechanic that decides who's tagged.

Open Source

Fully open source and free. View the code, fork it, or contribute on GitHub. Built with Java and Forge.

Install

Drop the .jar into your Forge mods folder and launch Minecraft. No extra setup needed.
